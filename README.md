One dad joke, told out loud at the dinner table, written by a program for the
[Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

`main.py` writes a single dad joke to `/output/entry.txt`.
